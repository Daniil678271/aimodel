# Gemini Telegram Bot

Telegram-бот на Python, работающий на Google Gemini API. Отвечает на любые вопросы, решает задачи по фотографиям, помнит контекст диалога и готов к круглосуточной работе на сервере.

## Возможности

| Функция | Как работает |
|---|---|
| Решение задач по фото | Фото, снимок тетради/учебника/теста/скриншота → распознавание → решение → подробное объяснение |
| Универсальный ассистент | Любые предметы и темы, программирование, тексты, переводы, исправление ошибок |
| Анализ изображений | Текст, графики, таблицы, схемы, документы, скриншоты; также PDF-файлы |
| Альбомы | Несколько фото, отправленных вместе, обрабатываются одним запросом |
| Изображения как файлы | Принимаются фото «как документ» (без сжатия — лучше для мелкого текста) |
| История диалога | Хранится отдельно для каждого пользователя в SQLite, переживает перезапуск |
| Интерфейс | `/start`, `/help`, `/reset`, `/mode`, кнопки меню, индикатор «печатает…» и статус «Анализирую…» |
| Режимы ответа | «Подробно» (пошагово) и «Кратко» — переключаются через `/mode` |
| Длинные ответы | Автоматическое разбиение под лимит Telegram, блоки кода не разрываются |
| Ошибки | Понятные сообщения: лимиты API, перегрузка, блокировка фильтрами, битые/большие файлы |
| Безопасность | Секреты только в `.env`, токен не попадает в логи, белый список, лимиты запросов |
| Надёжность | Повторы запросов с паузами, резервная модель, автоперезапуск в Docker/systemd |

## Шаг 1. Создание Telegram-бота через @BotFather

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) (проверьте, что у аккаунта синяя галочка).
2. Отправьте команду `/newbot`.
3. Введите **имя** бота — оно отображается в чатах (например, `Мой Gemini`).
4. Введите **username** — уникальное, обязательно оканчивается на `bot` (например, `my_gemini_helper_bot`).
5. BotFather пришлёт **токен** вида `123456789:AAExampleExampleExampleExample`. Это пароль от бота: никому не показывайте. Если токен утёк — отправьте BotFather `/revoke` и получите новый.
6. По желанию: `/setdescription`, `/setabouttext`, `/setuserpic` — оформление профиля бота.

## Шаг 2. Получение Gemini API key

1. Откройте [Google AI Studio → API keys](https://aistudio.google.com/apikey) и войдите в Google-аккаунт.
2. Нажмите **Create API key** (при необходимости создайте или выберите проект).
3. Скопируйте ключ. Не публикуйте его и не отправляйте в чаты.

Бесплатный уровень работает без привязки карты, но ограничен по запросам в минуту и в сутки. Кроме того, Google может использовать данные бесплатного уровня для улучшения своих продуктов — не отправляйте через бота конфиденциальные данные. Актуальные лимиты и условия: <https://ai.google.dev/gemini-api/docs/pricing>.

> **Регион.** Gemini API доступен не во всех странах. Если в логах или в чате появляется ошибка «User location is not supported», запустите бота на сервере в поддерживаемой стране.

## Шаг 3. Настройка `.env`

```bash
cp .env.example .env
nano .env          # или любой редактор
chmod 600 .env     # на Linux/macOS: файл читает только владелец
```

Обязательно заполните:

```
TELEGRAM_BOT_TOKEN=токен_от_BotFather
GEMINI_API_KEY=ключ_из_AI_Studio
```

### Все настройки

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен бота (обязательно) |
| `GEMINI_API_KEY` | — | Ключ Gemini API (обязательно) |
| `GEMINI_MODEL` | `gemini-3.6-flash` | Основная модель. Меняется без правки кода |
| `GEMINI_FALLBACK_MODEL` | `gemini-3.5-flash` | Резервная модель при перегрузке, исчерпанном лимите или 404 основной. Пусто — отключить |
| `GEMINI_TEMPERATURE` | не задана | Креативность. Для Gemini 3 лучше оставить пустой |
| `GEMINI_MAX_OUTPUT_TOKENS` | `16384` | Максимум токенов ответа (включая «размышления» модели) |
| `GEMINI_REQUEST_TIMEOUT` | `120` | Таймаут запроса, секунды |
| `GEMINI_USE_SEARCH` | `false` | Google Search grounding — ответы с данными из интернета (см. раздел про платные функции) |
| `MAX_HISTORY_MESSAGES` | `24` | Сколько последних сообщений помнить (0 — не хранить историю) |
| `MAX_FILE_MB` | `15` | Максимальный размер файла |
| `RATE_LIMIT_PER_MINUTE` | `10` | Запросов в минуту на пользователя (0 — без лимита) |
| `DAILY_LIMIT_PER_USER` | `0` | Запросов в сутки на пользователя, по UTC (0 — без лимита) |
| `ALLOWED_USER_IDS` | пусто | Белый список Telegram ID через запятую. Пусто — доступ у всех |
| `DATABASE_PATH` | `data/bot.db` | Путь к базе SQLite |
| `LOG_LEVEL` | `INFO` | Уровень логирования |

### Выбор модели

Список моделей, доступных вашему ключу:

```bash
python -m scripts.list_models
```

> **Важно.** Модели `gemini-2.5-flash`, `gemini-2.5-flash-lite` и `gemini-2.5-pro` по графику Google выводятся из эксплуатации **16 октября 2026**. Не используйте их. Названия моделей меняются, поэтому перед запуском сверьтесь с <https://ai.google.dev/gemini-api/docs/models> и при необходимости обновите `GEMINI_MODEL`. Подойдёт любая модель Gemini с поддержкой изображений (серия Flash — оптимальный баланс скорости и цены).

### Как узнать свой Telegram ID для белого списка

Напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт числовой ID. Для нескольких пользователей: `ALLOWED_USER_IDS=111111111,222222222`.

## Шаг 4. Запуск

### Вариант A. Локально (для проверки)

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot.main
```

В логах должны появиться строки `Бот запущен: @имя_бота` и `Gemini API доступен`. Откройте бота в Telegram и отправьте `/start`.

### Вариант B. Docker (рекомендуется для сервера)

```bash
docker compose up -d --build
docker compose logs -f
```

Контейнер перезапускается автоматически (`restart: unless-stopped`), в том числе после перезагрузки сервера. История диалогов хранится в томе Docker `bot-data` и не пропадает при обновлении.

## Размещение на сервере для работы 24/7

Подойдёт любой VPS (Ubuntu 22.04/24.04, 1 vCPU и 512 МБ–1 ГБ ОЗУ достаточно). Входящие порты открывать **не нужно**: бот сам опрашивает Telegram (long polling).

### Через Docker

```bash
# 1. Установка Docker (официальный скрипт)
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER        # затем выйдите и войдите по SSH заново

# 2. Загрузите проект на сервер (с вашего компьютера):
scp -r gemini-telegram-bot user@SERVER_IP:~/
#    либо git clone, если проект лежит в приватном репозитории

# 3. Настройка и запуск
cd ~/gemini-telegram-bot
cp .env.example .env && nano .env && chmod 600 .env
docker compose up -d --build
```

Полезные команды:

```bash
docker compose ps                    # состояние
docker compose logs -f --tail=100    # логи
docker compose restart               # перезапуск
docker compose down                  # остановка

# Обновление после правки кода или смены версии зависимостей
docker compose up -d --build

# Резервная копия истории и настроек
docker run --rm -v gemini-telegram-bot_bot-data:/data -v "$PWD":/backup alpine \
    tar czf /backup/bot-data-backup.tgz -C /data .
```

Рекомендации по безопасности сервера: вход по SSH-ключам, отключённый вход по паролю, `sudo ufw allow OpenSSH && sudo ufw enable`, регулярные обновления (`sudo apt update && sudo apt upgrade`).

### Без Docker: systemd

```bash
sudo apt update && sudo apt install -y python3 python3-venv
sudo useradd --system --home /opt/gemini-telegram-bot --shell /usr/sbin/nologin gemini-bot

sudo mkdir -p /opt/gemini-telegram-bot
sudo cp -r bot scripts requirements.txt .env.example /opt/gemini-telegram-bot/
cd /opt/gemini-telegram-bot
sudo cp .env.example .env && sudo nano .env
sudo mkdir -p data
sudo python3 -m venv .venv
sudo .venv/bin/pip install -r requirements.txt
sudo chown -R gemini-bot:gemini-bot /opt/gemini-telegram-bot
sudo chmod 600 /opt/gemini-telegram-bot/.env

sudo cp /путь/к/проекту/deploy/gemini-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now gemini-bot

sudo systemctl status gemini-bot
sudo journalctl -u gemini-bot -f
```

Сервис перезапускается при любом сбое (`Restart=always`) и стартует вместе с сервером.

## Как это работает

- **Фото.** Telegram присылает фото в нескольких размерах — берётся самое большое. Pillow исправляет поворот по EXIF, уменьшает сторону до 2048 px и сохраняет JPEG: качество достаточно для мелкого текста, а запрос быстрее и дешевле. Изображение отправляется в Gemini вместе с вашей подписью (или стандартной инструкцией «определи и реши»).
- **История.** В базе хранятся последние `MAX_HISTORY_MESSAGES` сообщений (текст вопросов и ответов). Сами изображения не сохраняются: в истории остаётся пометка о вложении и полный текст решения, поэтому уточнения вроде «объясни шаг 3» работают, а повторное «посмотри на фото» — нет.
- **Очередь на пользователя.** Запросы одного пользователя выполняются по очереди, чтобы порядок сообщений в истории не нарушался; разные пользователи обслуживаются параллельно.
- **Форматирование.** Ответ Gemini (Markdown) преобразуется в HTML-разметку Telegram. Если Telegram отклоняет разметку, сообщение отправляется простым текстом.
- **Надёжность.** При ошибках 429/5xx и таймаутах — до 3 попыток с нарастающей паузой, затем резервная модель.
- **Только личные чаты.** Бот отвечает в приватных диалогах. Редактирование сообщений не вызывает повторный ответ.

## Что требует платных сервисов или дополнительных API

- **Платный тариф Gemini.** Бесплатный уровень ограничен по частоте и суточному объёму. При большом числе пользователей подключите оплату в Google AI Studio / Google Cloud и задайте `DAILY_LIMIT_PER_USER`, чтобы контролировать расходы.
- **Google Search grounding** (`GEMINI_USE_SEARCH=true`). Даёт ответам доступ к свежим данным из интернета. Тарификация и лимиты определяются Google и могут отличаться от обычных запросов — проверьте на странице цен перед включением.
- **Не входит в проект:** генерация изображений, распознавание и синтез голоса, видео. Для них у Gemini есть отдельные модели и методы; их нужно добавлять отдельно (и они тарифицируются отдельно).
- **HEIC/HEIF.** Фото в формате HEIC без доп. библиотеки не читаются. Чтобы добавить поддержку: `pip install pillow-heif` и вызов `pillow_heif.register_heif_opener()` в начале `bot/media.py`.

## Безопасность

- Токены и ключи только в `.env` (в `.gitignore` и `.dockerignore` — в Git и образ не попадут). Права `chmod 600 .env`.
- Логи httpx (в которых мог бы светиться токен бота) принудительно приглушены.
- Контейнер запускается от непривилегированного пользователя.
- Защита от злоупотреблений: `RATE_LIMIT_PER_MINUTE`, `DAILY_LIMIT_PER_USER`, `ALLOWED_USER_IDS`, лимит размера файлов.
- Если ключ или токен попали в чужие руки — немедленно отзовите: токен через `/revoke` у BotFather, ключ в Google AI Studio.

## Совместимость и проверка API

Проект рассчитан на Python 3.11+ (проверялась работа кода на Python 3.12) и использует:

| Библиотека | Версия | Используемые методы |
|---|---|---|
| python-telegram-bot | `>=21.6,<24` | `Application.builder()`, `concurrent_updates`, `run_polling`, `CommandHandler`, `MessageHandler`, `CallbackQueryHandler`, `filters.Document.IMAGE/PDF`, `Bot.get_file`, `File.download_as_bytearray`, `LinkPreviewOptions`, `send_chat_action` |
| google-genai (официальный Google Gen AI SDK) | `>=1.50.0` | `genai.Client(api_key, http_options)`, `client.aio.models.generate_content`, `client.aio.models.get`, `client.models.list`, `types.Part.from_text/from_bytes`, `types.Content`, `types.GenerateContentConfig`, `errors.APIError` |
| Pillow | `>=10.4.0` | `Image.open`, `ImageOps.exif_transpose`, `Image.Resampling.LANCZOS` |
| python-dotenv | `>=1.0.1` | `load_dotenv` |

Что именно проверено при подготовке проекта:

- Синтаксис всех модулей (`py_compile`) и логика форматирования/разбиения длинных ответов (`bot/utils.py`) — прогнаны автономными тестами.
- Названия моделей и сроки вывода из эксплуатации сверены с документацией Google на момент подготовки (октябрь 2026).

Чего проверить не удалось: реальные вызовы Telegram и Gemini требуют ваших токенов и сети, поэтому **первый запуск — это и есть интеграционный тест**. Начните с локального запуска, отправьте боту текст, затем фото задачи, затем длинный запрос (например, «напиши подробное сочинение на 1500 слов»), и проверьте логи. Если версия библиотеки изменила какой-то метод, ошибка будет видна в логах с точным названием.

## Решение проблем

| Симптом | Причина и решение |
|---|---|
| `Ошибка настройки: Не задан TELEGRAM_BOT_TOKEN` | Файл `.env` не создан или пуст. Запускайте из каталога проекта |
| Бот молчит | Проверьте логи; убедитесь, что запущен только один экземпляр с этим токеном (иначе ошибка `Conflict`) |
| `Conflict: terminated by other getUpdates request` | Тот же токен используется другим процессом (локально и на сервере одновременно). Остановите лишний |
| «Модель … не найдена» | Модель переименована или выведена из эксплуатации. Выполните `python -m scripts.list_models` и обновите `GEMINI_MODEL` |
| «Достигнут лимит запросов Gemini API» | Исчерпан бесплатный лимит. Подождите, настройте резервную модель или подключите платный тариф |
| «Gemini API недоступен из региона» | Запускайте бота на сервере в стране, где Gemini API поддерживается |
| Ответ пришёл без форматирования | Telegram отклонил разметку — сработал безопасный запасной вариант, это нормально |
| `Permission denied` для базы в Docker | Используйте именованный том из `docker-compose.yml` (не монтируйте папку `./data` от root) |
